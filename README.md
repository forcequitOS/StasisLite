# Stasis Lite
Why did I make a repo for this. Jailbreak package to disable updates on tvOS 9 - 26. Probably.

This does the exact same thing as [Stasis](https://github.com/forcequitOS/Stasis), just without the UI fluff. This is literally two shell scripts. There are zero binaries here. Works on any jailbroken Apple TV or something. I think. Probably. Tested a lot less.
